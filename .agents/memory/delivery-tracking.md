---
name: Manual delivery tracking
description: Scope rule for shipment tracking and TTN handling in the BUDBOX CRM.
---

The CRM must treat Nova Poshta TTN and delivery status as manually maintained unless a live integration is actually connected. Do not imply that the UI generates shipments or monitors delivery automatically.

**Why:** The user asked to keep delivery tracking manual and not imply a live Nova Poshta integration.

**How to apply:** Keep TTN and delivery status editable by staff. If a carrier integration is added later, describe its capabilities only after the API is wired and verified.
